# pauling.space

One static page. No build step.

- `index.html` is the whole site.
- `CNAME` tells GitHub Pages the custom domain.

Deploy: push to `main`, then Settings → Pages → Source: Deploy from a branch → `main` / root. Add the four A records and the `www` CNAME at your registrar, then tick Enforce HTTPS.
